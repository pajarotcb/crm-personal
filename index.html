ERROR CRÍTICO Campo RESPONSABLE — #REF! en fichas de clientes
RESPONSABLE → fórmula rota por columna eliminada
Afecta: clientes 1, 4, 5, 6, 8, 9, 10, 12, 20, 21, 22, 23, 24
Pendiente ▶

La fórmula original referenciaba una celda del CRM que fue eliminada o movida. Excel destruyó la referencia y la dejó como #REF!. Las fichas que sí funcionan bien usan un VLOOKUP contra la tabla principal — esa misma fórmula se puede aplicar a las fichas rotas.

Fórmula actual (rota)
=#REF!
Fórmula corregida
=VLOOKUP($B$2,'CRM '!$A$7:$N$41,2,FALSE)

Qué hace: busca el ID del cliente (celda B2 de cada ficha) en la tabla CRM y trae el nombre del responsable (columna 2 = columna B del CRM).

DATO INCORRECTO Campo FECHA ALTA — muestra el nombre del Responsable
FECHA ALTA → muestra "Moncho", "Tomi", etc. en vez de una fecha
Afecta: clientes 1, 2, 3, 4, 5, 6, 8, 9, 10, 12, 20, 21, 22, 23, 24
Pendiente ▶

La fórmula hace un VLOOKUP con índice 2 (columna B del CRM = "Responsable"). El campo FECHA ALTA no existe como columna en el CRM, así que la fórmula trae el dato equivocado. Hay dos opciones para corregirlo:

Opción A — Ingresar la fecha manualmente en cada ficha (recomendado)

Fórmula actual (incorrecta)
=VLOOKUP($B$2,'CRM '!$A$7:$N$27,2,FALSE)
Reemplazar por texto fijo
[ingresar fecha manualmente, ej: 01/08/2025]

Opción B — Agregar columna FECHA ALTA al CRM y actualizar el VLOOKUP

Fórmula actual (incorrecta)
=VLOOKUP($B$2,'CRM '!$A$7:$N$27,2,FALSE)
Con nueva columna (índice 3)
=VLOOKUP($B$2,'CRM '!$A$7:$O$41,3,FALSE)
DATO VACÍO Campo FECHA ACCION — muestra 1/0/1900 en vez de vacío
FECHA ACCION → celda vacía interpretada como fecha cero
Afecta: prácticamente todos los clientes
Pendiente ▶

La fórmula apunta a la celda donde debería estar la fecha del próximo paso PENDIENTE. Cuando esa celda está vacía, Excel devuelve 0 y como el campo está formateado como fecha, muestra 1/0/1900. No hay un dato equivocado — simplemente falta la fecha. La corrección agrega un condicional para mostrar vacío en ese caso, y usa LOOKUP dinámico para encontrar automáticamente la última fecha cargada.

Fórmula actual (varía por ficha)
=+D52    o    =+D38
Fórmula corregida (dinámica)
=IFERROR(LOOKUP(2,1/(D28:D100<>""),D28:D100),"")

Qué hace: busca la última celda no vacía en la columna D de la tabla de seguimiento y la muestra. Si no hay ninguna, muestra vacío en vez de 1/0/1900. El rango D28:D100 puede ajustarse al rango real de cada ficha.
